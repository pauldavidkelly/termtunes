    **Step 2: Create src/tui.rs -- Terminal lifecycle**

    Implement three functions per research Pattern 1:

    - `restore_terminal()` -- disables raw mode, leaves alternate screen, shows cursor. Uses `let _ =` to suppress errors (cleanup must not panic).
    - `install_panic_hook()` -- calls `std::panic::take_hook()`, wraps original hook with `restore_terminal()` call before delegating. Install BEFORE terminal init.
    - `install_signal_handlers() -> Arc<AtomicBool>` -- registers SIGINT, SIGTERM, SIGHUP via `signal_hook::flag::register`. Returns the shared `shutdown` AtomicBool flag.

    Use `crossterm::terminal::{disable_raw_mode, LeaveAlternateScreen}`, `crossterm::cursor::Show`, and `crossterm::execute!` on stdout.

    **Step 3: Create src/config.rs -- Config persistence**

    Implement per research Pattern 4:

    - `Config` struct: `client_id: String`, `last_server: Option<String>`, `servers: HashMap<String, ServerConfig>`. Derive Serialize, Deserialize, Default.
    - `ServerConfig` struct: `name: String`, `url: String`, `token: String`. Derive Serialize, Deserialize.
    - `config_path() -> PathBuf` -- uses `dirs::config_dir()` with fallback to `~/.config`, appends `termtunes/config.toml`.
    - `load_config() -> Result<Config>` -- if file exists, read and deserialize; else create new Config with `uuid::Uuid::new_v4().to_string()` as client_id.
    - `save_config(config: &Config) -> Result<()>` -- create parent dirs, serialize to TOML pretty, write file, set permissions to 0o600.

    Use `color_eyre::Result` for error types throughout.

    **Step 4: Create src/app.rs -- App state skeleton**

    - `App` struct with fields: `config: Config`, `running: bool`, `shutdown: Arc<AtomicBool>`.
    - `App::new(config: Config, shutdown: Arc<AtomicBool>) -> Self`
    - `App::run(&mut self, terminal: &mut ratatui::DefaultTerminal) -> Result<()>` -- event loop that:
      1. Checks `self.shutdown.load(Ordering::Relaxed)` for signal exit
      2. Draws a placeholder "TermTunes - press q to quit" message via `terminal.draw()`
      3. Polls for crossterm keyboard events with 100ms timeout
      4. Handles `q` key to set `self.running = false`
      5. Loops while `self.running`

    **Step 5: Create src/main.rs -- Entry point**

    Wire everything together:
    1. `color_eyre::install()?`
    2. Initialize tracing subscriber (write to file at `~/.local/share/termtunes/termtunes.log`, create dirs if needed)
    3. `tui::install_panic_hook()`
    4. `let shutdown = tui::install_signal_handlers()`
    5. `let config = config::load_config()?`
    6. `config::save_config(&config)?` (ensures config file exists on first run)
    7. `let mut terminal = ratatui::init()`
    8. `let mut app = App::new(config, shutdown)`
    9. `let result = app.run(&mut terminal)`
    10. `ratatui::restore()`
    11. `result` (propagate any error)

    Declare modules: `mod tui; mod config; mod app;`
