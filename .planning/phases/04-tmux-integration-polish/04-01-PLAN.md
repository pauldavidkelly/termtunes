**In src/ui.rs:**

1. Add a `truncate_for_display(s: &str, max_chars: usize) -> String` helper function at the bottom of the file. If `s.chars().count() <= max_chars`, return `s.to_string()`. If `max_chars <= 3`, return `s.chars().take(max_chars).collect()`. Otherwise return `s.chars().take(max_chars - 3).collect::<String>() + "..."`.

2. At the top of `render()`, add minimum size guard and narrow-mode flag:
   ```rust
   let area = frame.area();
   let width = area.width;

   // Minimum viable display -- below this, just show a message
   if width < 20 || area.height < 5 {
       let msg = Paragraph::new("Terminal too small")
           .style(Style::default().fg(Color::Red))
           .alignment(Alignment::Center);
       frame.render_widget(msg, area);
       return;
   }

   let is_narrow = width < 40;
   ```

3. Pass `is_narrow` and `width` to sub-renderers that need it. Modify the function signatures:
   - `render_playlists(frame, app, area)` -> `render_playlists(frame, app, area, width)`
   - `render_tracks(frame, app, area)` -> `render_tracks(frame, app, area, width)`
   - `render_player_bar(frame, app, area)` -> `render_player_bar(frame, app, area, is_narrow, width)`
   - `render_status_bar(frame, app, area)` -> `render_status_bar(frame, app, area, is_narrow)`

4. In `render_playlists`: Truncate playlist names to fit available width. The available chars are roughly `width - 4` (borders + highlight symbol). Use `truncate_for_display` on the final formatted string (fav_prefix + title + count). If narrow and the combined string exceeds available width, drop the track count suffix first.

5. In `render_tracks`: Truncate track display strings. Available chars are roughly `width - 4`. For playing tracks (`>> Title - Artist`), truncate the combined string. For non-playing tracks (`   Title - Artist`), truncate similarly.

6. In `render_player_bar`:
   - Line 1 (track info): In narrow mode (`is_narrow`), show only the state icon + track name (truncated), omitting artist and album. In normal mode, keep the current multi-span layout but truncate the entire line if it would exceed width.
   - Line 3 (status): In narrow mode, show only the state label + time (drop volume, shuffle, repeat indicators). In normal mode, keep current behavior.

7. In `render_status_bar`: In narrow mode, shorten the help text to something like `" q:quit j/k:nav Enter:sel Space:pause"` (just the essential keys). In normal mode, keep the current full help text.

**In src/app.rs:**

8. Change the event polling block in `run()` from:
   ```rust
   if event::poll(Duration::from_millis(100))? {
       if let Event::Key(key) = event::read()? {
           if key.kind == KeyEventKind::Press {
               self.handle_key(key.code, key.modifiers).await?;
           }
       }
   }
   ```
   To:
   ```rust
   if event::poll(Duration::from_millis(100))? {
       match event::read()? {
           Event::Key(key) if key.kind == KeyEventKind::Press => {
               self.handle_key(key.code, key.modifiers).await?;
           }
           Event::Resize(_w, _h) => {
               // Fullscreen ratatui auto-resizes buffers on next draw().
               // No action needed -- loop continues and draw() is called.
           }
           _ => {}
       }
   }
   ```
   This explicitly handles resize events instead of silently dropping them.

- Define `const NARROW_WIDTH: u16 = 40;` and `const MIN_WIDTH: u16 = 20;` and `const MIN_HEIGHT: u16 = 5;` at the top of ui.rs for clarity.
- Do NOT change any existing keybinding behavior or playback logic.
