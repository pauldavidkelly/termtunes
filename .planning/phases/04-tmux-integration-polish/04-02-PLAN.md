  <name>Task 1: Add Session struct to config.rs, now-playing file writer and session save/restore to app.rs, and startup restore to main.rs</name>
  <files>src/config.rs, src/app.rs, src/main.rs</files>
  <action>
**In src/config.rs:**

1. Add a `Session` struct with serde derives:
   ```rust
   #[derive(Serialize, Deserialize, Default, Debug)]
   pub struct Session {
       pub playlist_rating_key: Option<String>,
       pub playlist_title: Option<String>,
       pub track_index: Option<usize>,
       pub volume: f32,
       pub shuffle_enabled: bool,
       pub repeat_mode: String, // "off", "all", "one"
   }
   ```

2. Add `session_path() -> PathBuf` function: Returns `dirs::data_dir().join("termtunes").join("session.toml")` with the same fallback pattern as `config_path()`.

3. Add `load_session() -> Option<Session>` function: Read session.toml if it exists, deserialize with `toml::from_str`. Return None if file missing or parse fails. Do NOT propagate errors -- session restore is best-effort.

4. Add `save_session(session: &Session) -> Result<()>` function: Create parent dirs, serialize to TOML, write to session_path(). Use 0o600 permissions for consistency with config file.

5. Add `now_playing_path() -> PathBuf` function: Returns `dirs::data_dir().join("termtunes").join("now_playing")` with fallback.

**In src/app.rs:**

6. Add a `write_now_playing_file(content: &str)` free function (not a method on App). It writes the content to `config::now_playing_path()`. Best-effort: use `let _ = std::fs::write(...)` wrapped in a tracing::warn on error. Ensure parent dir exists (create_dir_all).

7. Call `write_now_playing_file` at these points:
   - In `check_download_complete` after successfully starting playback: write `"{artist} - {track_name}"`.
   - In `handle_key` when spacebar toggles pause: if pausing, write `"|| {artist} - {track_name}"`; if resuming, write `"{artist} - {track_name}"`.
   - When the app exits (in the `run()` method, after the while loop ends): write `""` (empty string to clear the file).
   - When a track finishes (auto-advance or stop): update the file content accordingly. If stopping (no next track), write `""`.

8. Add a `save_session_state(&self)` method on App. It constructs a `config::Session` from current state:
   - `playlist_rating_key`: Get rating_key from the currently selected/playing playlist. The playlists list is available -- use the playlist that matches `self.current_playlist_title`, or store the rating_key when a playlist is selected. Simplest approach: add a `current_playlist_rating_key: Option<String>` field to App struct, set it when entering Tracks/Playing view (alongside current_playlist_title).
   - `playlist_title`: From `self.current_playlist_title`.
   - `track_index`: From `self.current_track_index`.
   - `volume`: From `self.saved_volume`.
   - `shuffle_enabled`: From `self.shuffle_enabled`.
   - `repeat_mode`: Map RepeatMode enum to string: Off -> "off", All -> "all", One -> "one".
   Call `config::save_session(&session)` and log any error without panicking.

9. Add a `current_playlist_rating_key` field (Option<String>) to the App struct. Initialize it as None. Set it whenever tracks are loaded for a playlist:
   - In the handle_key Enter handler for Playlists view (where tracks are fetched), set it from the selected playlist's rating_key.
   - In `start_favorite`, set it from the favorite's rating_key.

10. Add a `pub async fn restore_session(&mut self)` method. It:
    - Calls `config::load_session()`. If None, return immediately.
    - Finds the saved playlist in `self.playlists` by matching `playlist_rating_key`. If not found, log warning and return (playlist may have been deleted from Plex).
    - Fetches tracks for the matched playlist via `self.plex_client.fetch_tracks(&rating_key).await`. On error, log warning and return.
    - Sets `self.tracks`, `self.current_playlist_title`, `self.current_playlist_rating_key`.
    - Sets `self.track_state` selection to `session.track_index` (clamped to tracks.len() - 1 if out of bounds).
    - Sets `self.saved_volume` to `session.volume` (clamped to 0.0..=1.0).
    - Sets `self.shuffle_enabled` to `session.shuffle_enabled`.
    - Sets `self.repeat_mode` from `session.repeat_mode` string: "all" -> All, "one" -> One, _ -> Off.
    - Sets `self.view` to `AppView::Tracks` (NOT Playing -- do NOT auto-play).
    - Selects the playlist in playlist_state to match the restored playlist index.
    - Does NOT call play_track_at_index. The user is positioned at the saved track and presses Enter/Space to resume.

11. In `run()`, after the while loop ends (right before `Ok(())`), call `self.save_session_state()` to persist state on graceful exit. Also call `write_now_playing_file("")` to clear the tmux file.

**In src/main.rs:**

12. After creating the App instance (line 85: `let mut app = App::new(...)`) and before `app.run(...)`, call `app.restore_session().await;`. This is best-effort -- any errors are logged but do not prevent the app from starting.

**Key constraints:**
- Do NOT auto-play on session restore. Position only.
- Save session ONLY on graceful exit (q key, signal shutdown). Do NOT save on every track change.
- now_playing file writes are best-effort. Never panic on write failure.
- Use 0o600 permissions for session.toml (consistency with config.toml).
- RepeatMode to/from string conversion: add a `to_string_repr(&self) -> &str` method and a `from_string_repr(s: &str) -> Self` associated function on RepeatMode in app.rs.
