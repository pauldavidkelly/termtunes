  <action>
Extend the Player struct in player.rs with volume and position methods. All methods delegate to the rodio Sink API -- no custom state tracking needed for these.

Add these public methods to the `impl Player` block:

1. `pub fn volume(&self) -> f32` -- returns `self.sink.volume()`. Current volume level (0.0 to 1.0).

2. `pub fn volume_up(&self)` -- increases volume by 0.05, clamped to 1.0 max. Uses `self.sink.set_volume((self.sink.volume() + 0.05).min(1.0))`.

3. `pub fn volume_down(&self)` -- decreases volume by 0.05, clamped to 0.0 min. Uses `self.sink.set_volume((self.sink.volume() - 0.05).max(0.0))`.

4. `pub fn get_pos(&self) -> std::time::Duration` -- returns `self.sink.get_pos()`. Current playback position. Note: can briefly exceed track duration near end (caller must clamp).

5. `pub fn set_volume(&self, vol: f32)` -- sets volume directly. Used by app.rs to restore saved volume after creating a new Sink. Calls `self.sink.set_volume(vol.clamp(0.0, 1.0))`.

Also modify `load_and_play()` to accept a saved volume level and apply it after creating the fresh Sink. Change the signature to:
```rust
pub fn load_and_play(&mut self, audio_bytes: Vec<u8>, track_name: String, volume: f32) -> Result<()>
```

After the line `self.sink = Sink::connect_new(self._stream.mixer());`, add:
```rust
self.sink.set_volume(volume.clamp(0.0, 1.0));
```

This ensures volume persists across track changes (Research finding: each new Sink starts at volume 1.0, so we must explicitly restore the saved level).

Do NOT cap volume at 1.0 in the `set_volume` method -- use `clamp(0.0, 1.0)` to handle both bounds. Values above 1.0 cause clipping per research.

**4. Track index management methods:**

Add `play_track_at_index` -- the shared core for next/prev/select:
```rust
fn play_track_at_index(&mut self, index: usize) -> Result<()> {
    if index >= self.tracks.len() { return Ok(()); }
    // Cancel any in-progress download by dropping the old receiver
    self.download_rx = None;
    // Update index and sync list selection
    self.current_track_index = Some(index);
    self.track_state.select(Some(index));
    // Use existing download mechanism
    self.start_track_download()
}
```

Add `next_track`:
```rust
fn next_track(&mut self) -> Result<()> {
    if self.tracks.is_empty() { return Ok(()); }
    let next = match self.current_track_index {
        Some(idx) if idx + 1 < self.tracks.len() => idx + 1,
        _ => 0, // Wrap to beginning
    };
    self.play_track_at_index(next)
}
```

Add `prev_track`:
```rust
fn prev_track(&mut self) -> Result<()> {
    if self.tracks.is_empty() { return Ok(()); }
    let prev = match self.current_track_index {
        Some(0) | None => self.tracks.len().saturating_sub(1),
        Some(idx) => idx - 1,
    };
    self.play_track_at_index(prev)
}
```
